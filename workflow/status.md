# 상태 조회

개정: 2026-11-17

index와 질문 대상의 최신 기록·대상 버전만 읽고 필요한 근거로 좁혀 간다. 다른 완료 Task·전체 이력·설치·모델 설정은 읽지 않는다. index는 마지막 갱신 시점의 요약이며 실시간 생존 신호가 아니다. 오래됐으면 대상 문서의 현재 위치·버전·근거를 확인한다.

Task 상태는 원본 작업 문서의 위치로 확인한다. 시험 통과, 작업 수락, 단계 종료, 전체 완료, 프로세스 종료를 구분한다. 오래된 상태를 근거로 담당을 빼앗거나 작업을 재시작하지 않는다. 조회는 기록·상태를 변경하지 않는다.

TC 개수·내용·현황을 요청하면 [TC 조회 규칙](records-evidence.md#tc-현황-조회)을 읽고 질문 범위의 원본만 집계한다. 별도 에이전트의 조회에도 같은 기준을 적용한다.
