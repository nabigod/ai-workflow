# 역할별 모델 배정

개정: 2026-11-17 · 관리 구조 버전: `5`

| 역할 | 최초 단계 | 책임 |
|---|---|---|
| 계획 | 3단계 | 초기 계획·중요한 재계획 |
| 총괄 | 2단계 | 자동 배정·중지·재개 |
| 실행·REV | 1단계 | 제작·자체 검증 |
| 통합 | 2단계 | 검토·수락·연결 검증 |
| 사용자검증 | 1단계 | 사용자 시험 안내·기록 |
| 커밋목록 | 1단계 | 변경 조사·파일 단위 목록 |

모델 계열·버전은 entry에서 선택한 현재 환경 프로필 하나만 읽는다. 사용자 지정 환경·모델·버전·추론 강도가 우선하며 예외를 작업에 기록한다. 계열의 최신 버전이 기본이고 표의 버전은 사용자 지정 기준값이다. 배정 시작 시 현재 환경의 모델 목록·공식 안내에서 실제 선택명·가용성을 확인한다. 확인이 안 되면 기준값과 한계를 밝히고 사용 가능한 설정을 확인한다. 진행 중 담당자를 새 버전 발표만으로 교체하지 않는다.

추론 강도 선택이 가능하면 high를 요청한다. 미지원이면 실제 기본 설정과 미지원을 구분한다. 다른 계열 식별자를 추정하지 않으며 요청 설정과 실제 확인 설정을 구별한다. 확인되지 않은 값은 확인 불가다. 태그·문서만으로 현재 대화의 모델이 바뀌지 않는다.

최초 시도는 지정 단계다. 난도·위험·시간 절약·지시서 권고만으로 최초 실행·REV를 높이지 않는다. 필요한 모델·설정·위임이 없으면 제한과 수동 인계를 보고한다. 자동 모드는 시작하지 않고 수동 모드의 가능한 수행 방식은 사용자와 확인한다. 고급 모델의 직접 수행을 저렴한 모델 위임으로 기록하지 않는다.

실행·통합은 동일 문제에 지정 단계로 최초 포함 2회 실패 후 바로 위 단계 1회만 허용한다. 실패 후 재시도 또는 실패 이력 작업 배정 전에 [재시도 원문](models-retry.md)을 읽는다. 계획·총괄은 작업 실패로 자동 상향하지 않는다. 사용자 지정 한도가 우선하며 단계표 밖 모델의 상향 경로를 추정하지 않는다.
