# 프로젝트 기록 안내

개정: 2026-11-17 · 관리 구조 버전: `5`

원문을 사용 시점별로 분리했다. 이 목록을 따라 모두 읽지 말고 [entry](entry.md)의 현재 역할·조건에 해당하는 문서를 선택한다.

- 기존 2절: [관리 구조 생성](records-layout.md). 기존 프로젝트 전환은 사용자 요청 때 [전환](migration.md)을 적용한다.
- 기존 4절: [작업 식별·상태·결과 기록](records-state.md).
- 기존 5절: [테스트케이스·증빙·버전·현황 조회](records-evidence.md).

기존 프로젝트의 구조 버전·작업 ID·상태 폴더는 그대로다. 문서 분리만으로 프로젝트 기록을 이동하거나 변환하지 않는다.
