# MCP로 고정 원문 읽기

개정: 2026-11-17

`get_workflow_status`의 commit과 snapshot_uri를 고정하고 `read_workflow_document`에 그 커밋과 묶음 내 상대 경로를 지정한다. entry부터 현재 역할·환경·조건의 원문만 읽는다. 상대 링크는 같은 스냅샷 기준이며 호스트 절대 경로를 SSH 서버 로컬 경로로 해석하지 않는다.

상태·본문 읽기는 fetch가 아니다. sync_status의 마지막 원격 확인과 observed_at/read_at의 이번 읽기를 구분한다. active가 바뀌어도 기존 작업은 고정 커밋을 사용한다. 사본이나 MCP 접근이 없으면 최신 버전·다른 로컬 경로로 임의 대체하지 않는다.

하위 담당자도 같은 커밋·원문에 접근해야 한다. MCP 없는 담당자에게 원문을 전달했다면 직접 MCP 읽기와 구분한다. 연결 확인만 요청받으면 status·entry만 읽고 필수 목록을 보고하며 본문 읽기·프로젝트 실행·동기화를 수행했다고 주장하지 않는다.
