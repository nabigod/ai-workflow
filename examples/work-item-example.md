# T-01 입력 이름 길이 검증

이 문서는 짧은 작업지시서 작성 예시이며 실제 구현·시험 결과가 아니다. 정책은 [계획](../workflow/planning.md)과 [TC 원본](../workflow/records-evidence.md)을 따른다.

ID: T-01 · 요구사항: R-01 · 개정: 1 · 담당: 미배정 · 갱신: 2026-11-17

최신 제출: 미제출 · 다음: 실행 담당 배정 → 별도 통합 검토

## 지시

R-01: 입력 이름을 1~20자만 허용하고 빈 값·초과 길이는 오류로 반환한다. 기준 입력은 plan 개정 1이며 문자열 길이의 단위는 Unicode 코드 포인트다. 예시 사용자가 이 범위를 확정했다고 가정한다.

수정: src/name.py와 해당 검증 자료. 공개 API·외부 시스템 변경은 제외한다. 입력 접근·실행 허가 확보 후 시작하며 선행 작업은 없다. 병렬 불가: 동일 모듈을 수정하는 작업과 파일 소유권이 겹친다. 통합 순서는 이 작업 제출 후 검토다. 공통 규칙은 plan의 고정 버전을 참조한다. 작업량 소, 실행 1단계·통합 2단계, 사용자 모델 예외 없음. 외부 환경 검증은 필요 없다.

## 완료 조건·검증

모든 TC는 필수, 상태 미수행, 대상 버전 미제출, 수행 주체 실행 담당, 근거 없음이다. 검증 방법은 함수 호출의 반환값 비교다. 결과가 생기면 해당 항목에 상태·실제 버전·근거만 추가한다.

미착수. 지시서 자체 검토: 요구사항 대응·정상/오류/경계·입력/수정 범위·모델/소유권 확인. 작성 중 직접 검토하여 별도 반복 검토·에이전트 호출 없음.
